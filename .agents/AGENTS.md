# .agents 结构

修改本目录前读本文件。本目录放 Agent 过程材料与可复用能力，不放产品代码、构建产物、凭据或环境文件。

```text
.agents/
  notes/                 带日期的过程材料
    plans/               跨轮跟进的事项、依据与阶段结论
    audits/              依赖、安全与规范审查快照
    archives/            有保留依据的历史设计
  skills/                可复用的方法与模板
    repo-conventions/    规范入口：通用方法指向 SkillLoom，此处只列本仓库路径
```

## notes/

文件名以 `YYYY-MM-DD` 开头，目录按材料性质区分。同一问题只维护一份记录，更新时改日期并追加结论。

- 只保留未解决事项、必要决策依据与无法从 Git 或现有测试还原的证据。
- 删除可由 Git 还原的阶段性流水，例如逐次审查报告、补丁快照与临时清单。
- 过程材料不替代实时门禁或现行规范。现行事实写入 `docs/`。
- 本目录不参与行数、内容量与文档链接检查，不因此放宽写法要求。

## skills/

一个目录一个能力，入口文件名固定为 `SKILL.md`，frontmatter 包含 `name` 与 `description`。细则放 `references/`，可复制模板放 `assets/`，不把全部内容塞进入口文件。

- 只写可复用的方法与模板。带日期的一次性结论属于 `notes/`。
- 一个能力一个目录，不按文件类型拆分。
- 通用方法与模板维护在 SkillLoom 的 `repo-conventions`，本仓库只保留薄入口与路径索引，不复制第二份。
- 修改 skill 后核对引用它的入口文件与实际命令是否仍然一致。
- WorkBuddy 不自动加载本目录，引用时给出相对仓库根的路径。需要在工作区自动加载时，在 `.workbuddy/skills/` 建立同名入口并在其中指向本目录。

## 本目录约定

- 新增子目录先在本文件的树中登记，并写明职责。
- 不提交个人草稿、编辑器缓存与临时导出。
