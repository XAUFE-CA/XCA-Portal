# 关于我们

XCA 是西安财经大学的学术科技类学生社团，为不同基础的同学提供学习、研讨与协作的空间。
::

::section{.about-values .neoverse-prose}

## 社区理念

**真诚、包容、和谐、热爱**

重视平等交流、相互尊重与知识共享，欢迎不同学习阶段、不同技术方向的同学参与。
::

::section{.about-topic .neoverse-prose}

## 技术交流与知识分享

围绕计算机技术交流问题、分享经验，在讨论与研讨中理解知识，也让学习过程中的思考有机会被看见。
::

::section{.about-topic .neoverse-prose}

## 项目实践与开源协作

项目实践不限定技术栈，既面向实际需求，也支持技术探索。参与现有项目，或提出新的项目构想，通过讨论与协作共同推进。
::

::section{.about-participate .neoverse-prose}

## 从一次参与开始

参与贡献不以独立完成项目为前提。文档修正、问题复现与使用反馈，同样是有价值的贡献。
::
