# 文档写作规范（AI）

适用范围：空格与标点、用词与语气两节及 [术语体系](terminology/README.md) 适用于全仓库 Markdown 与产品双语文案，含根 `AGENTS.md`、README 与 `.agents/` 过程材料。其余各节约束 `docs/**/*.md`。根 `AGENTS.md` 的强制约束继续有效，冲突时以根规则为准。本文件约束写法，不改变文档事实依据和职责划分。

    browser-regression.md       浏览器回归观测、运行要求与结果记录

  architecture/                 架构说明与现行接口，只描述当前真实情况
    engineering-quality.md      环境与依赖维护、门禁分级、代码与文档规模阈值、CI 决策
    fonts.md                    字体角色、资源许可、加载与子集生成

      navigation.md             顶栏导航、主题与语言控件、共享 UI 与图标

## 写前

- 先确认事实依据。源码、配置、脚本输出优先于既有文档。不确认的内容不写成结论。
- 先查 [术语体系](terminology/README.md) 的对照表。未收录的条目先补表，再使用。一个概念只用一个词，不混用缩写、全称或中英文变体。
- 先确定该文档的单一职责。运行命令、CI 版本、正文内容等已有依据时只链接，不复制。

## 空格与标点

- 汉字与半角字母、数字、单位之间空一格：`Nuxt 4`、`3100 端口`、`1000 upem`、`GB2312 一级常用字`。
- 数字与 `%`、`°` 紧贴。版本号、路径、命令、代码标识符内部不插空格。
- 行内链接与左右文字之间空一格：`详见 [终端扩展接口](terminal-extending.md) 文档。`
- 链接紧邻标点、括号或行首行尾时不加空格：`见（[字体](#字体)）。`
- 行内代码、加粗、斜体只按中西文规则处理，不加额外空格：使用 `UiTerminalPrompt` 组件。
- 中文正文使用全角标点。全角标点前后不留半角空格。英文专名内部的点号、连字符保留。
- 分号与冒号只在确有并列或说明关系时使用。不写 `名称：项目；项目；项目` 这类多项长串，改用列表或独立句子。一句里出现两处或更多 `；`、`：` 时先拆分。独立的意思用句号分开，不把多个独立句子串联成一句。中文注释按独立句断句，不沿用英文注释的分号。
- 中文引号用双引号“内容”和单引号‘内容’，不用「」或英文引号。
- 标题的 `#` 是 Markdown 语法：`#` 后恰好一个空格，不把 `#` 当作中西文间距的对象。
- 日期写 `2026-10-25`。时间写 `14:30`。区间写 `100–900`。数字一律半角。

## 用词与语气

禁止比喻、营销和无法核实的模糊表达。能写对象、数量、条件或结果时，不写程度词。禁用词、抽象词与改写对照以 [术语、缩写与用词对照](terminology/terms.md) 为唯一来源。

- 不写“我们”“你可以”等对话口吻。规范条文用祈使句或“必须/应当/可以”，事实用陈述句。
- 不写“未来可能”“大概”“或许”代替未知。未知就写“未验证”，并给出验证方式。
- 不用“首先/其次/最后”凑结构。段落按事实关系组织。
- 加粗与“必须”只留给改变行为的分句。处处强调等于没有重点。

## 结构

- 每篇一个一级标题。标题层级连续，不跳级。标题写主题，不写“概述”“其他”。
- 先结论后依据。段落一个主题，列表只放并列项，步骤用编号。
- 一段只讲一件事。多个并列项或多个阶段不压进同一段，超过三句或需要回看的段落按主题拆开。
- 表格用于对比和映射。代码块标注语言。命令、路径、符号用行内代码。
- 仓库内链接用相对路径，外部链接用完整 URL。链接文字说明目标，不写“点击这里”。
- 不重复其他文档的规则和清单。用链接指向唯一维护处。
- 文档元数据用英文书写，正文保持中文：标题下一行以 `Status: adopted`、`Status: historical` 等值标注状态。历史文档标注 `Status: historical` 并给出替代文档，不机械删除有设计依据的记录。
- 计划、审计、验证快照写明日期，不写成长期规范。
- 正文不写“已实现”“即将支持”等状态标注。状态由源码、脚本和门禁承载，文档只描述当前事实。
- 现行事实不写日期和时间。带日期的观测、基线和验证记录归 `.agents/notes/`，docs 只描述当前状态。

## 格式与验证

- Markdown 由 Prettier 与 `prettier-plugin-markdown-compact-tables` 插件格式化：正文换行保留（`proseWrap: preserve`），表格单元格两侧各留一个空格，不对齐列宽。
- 文件使用 UTF-8、LF、末尾换行。空行分隔标题、段落、列表、代码块和表格。
- 写完运行 `bun run format:check`、`bun run check:docs` 与 `bun run check:budgets`。链接目标与禁用表述由 `check:docs` 机械校验，术语一致性仍需人工核对。
- 单个子目录 `AGENTS.md` 应当不超过 100 行，硬上限 120 行。超限先拆分职责，不调高阈值。
