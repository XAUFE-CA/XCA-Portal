# 站点导航与偏好控件

Status: adopted

本文描述顶栏的三级响应式布局、主题与语言控件、共享 UI 接入及门户图标。页面来源与源码职责见 [站点框架](README.md)，宽度变化与视图过渡见 [页面过渡与层级](transitions.md)。

## 导航与响应式布局

顶栏按可用 CSS 视口宽度分三级布局。

- 大于 `70rem` 时标识、主导航与设置同排，标识与设置两侧轨道等宽，主导航以顶栏中线居中，两侧文案的宽度变化不会推偏导航。
- 大于 `38rem` 且不大于 `70rem` 时保留同排主导航，将语言和主题放进菜单。
- 不大于 `38rem` 时主导航也放入菜单。

断点定义见 `SiteHeader.vue` 与 `app/assets/css/main.css`，修改时同步核对脚本和样式。

菜单使用共享 `UiPopover`，从四宫格按钮下方靠右弹出，不撑高顶栏。浮层定位、极光玻璃材质、进出动效、外部点击关闭及 Escape 焦点恢复由共享 UI 提供。菜单内语言与主题分组纵向排列，页面跳转或跨响应式断点后收起。宽屏与菜单复用同一组导航和设置组件。

主导航选中标记沿用共享 `spatial` 时长与减速缓动，不使用线性位移或弹性过冲。

顶栏在页顶铺开，滚动超过共享 `space-4` 对应距离后收成悬浮形态。

顶栏轮廓在两种状态下都保留底部的共享卡片圆角，收拢只改变宽度、上移量与顶部圆角，形变按共享时长线性推进，避免轮廓在数帧内跳到位。顶栏贴着窗口，页顶背后没有可折射的内容，因此通过共享 UI 的 `data-neoverse-glass-edge-stroke` 启用材质自带的绘制描边，描边取自 `--neoverse-material-edge-stroke`，门户不写自己的边缘实现。

包裹区域随实际内容计算高度，文档滚动条按实际顶栏高度避让。标识与菜单容器使用 Flex 居中，避免内联基线影响垂直位置。文档滚动条由布局直接服务端渲染并经 Teleport 移到 `body`，共享样式表据 `data-hide-native` 在首帧即隐藏原生条，刷新时不出现原生条与沉浸式轨道的替换和横向重排。`ClientOnly` 包裹会退回挂载后才隐藏的旧行为。

## 主题、语言与共享 UI

导航复用 `UiNavigationItem`，主题与语言复用 `UiSegmentedControl`。三组控件分别由共享 `UiControlSurface` 提供默认的 `glass-subtle` 外观，并通过 `edge-mode="local"` 使用相同的边缘绘制方式。内层导航项和分段控件使用 `surface="none"`，避免叠加独立背景与阴影，保留各自的选中样式与键盘操作。语言与主题外壳通过公开的 `--neoverse-control-surface-padding-inline` 复用纵向内边距，使四周留白一致。控件内部采用共享默认尺寸，门户不覆盖字号、点击区域、材质、滑块或焦点样式。

主题控件与 `xca theme` 共用 `useSiteTheme`，语言控件与终端服务共用 `useSiteLocale`。切换不重建会话。

顶栏的宽度过渡由共享 `useLayoutWidthMotion` 承担。门户只提供容器、目标选择器与触发值，采样、终点解析、`spatial` 时长与缓动、打断续接和终止条件都在共享库内。底层原语 `captureLayoutWidths` 与 `animateLayoutWidths` 位于 `@neoverse-ui/motion`，Vue 适配位于 `@neoverse-ui/vue`，门户不维护第二套测量与动画状态。

根节点通过 `data-theme` 支持 light、dark 和 system，主题选择保存在 `xca-theme` Cookie。`useSiteTheme` 与根组件用同一偏好生成 SSR 的选中项和根节点主题，不在水合后恢复默认选项。

根组件只在服务端向 Head 注册初始主题，客户端主题写入由 `useSiteTheme` 在过渡回调中执行，避免 Head 更新覆盖交互选择。`intro-gate.js` 在控件绘制前把旧 localStorage 偏好一次性迁移到 Cookie，迁移成功后移除旧值并重新请求 SSR，后续刷新不再迁移。

顶栏及语言、主题控件不参与首页入场位移、缩放或错峰动画。语言存储、服务端首屏与命令输出规则只维护在 [翻译规则](../../terminology/translation.md)。

切换选项时，选中背景的滑动与伸缩由共享分段控件提供。语言变化时，`SiteHeader` 通过共享 `useLayoutWidthMotion` 统一测量标识、主导航与偏好外壳的可见宽度，并在更新后先读取全部自然终点，再同时启动共享 `spatial` 宽度过渡，不缩放文字。

所有占宽区域按同一进度变化，避免标识宽度先改变、偏好随后伸缩，将整个导航控件推过终点后又拉回。连续切换从当前可见宽度接续，完成后恢复自动宽度。

首次渲染与水合不补播放动画。减少动态效果、尺寸变化及组件卸载会结束宽度动画。浏览器不支持动画接口时直接使用内容宽度。

文档根节点不参与路由快照，只在视图过渡期间为正文分配 `root` 过渡名称，并将快照层裁剪到实时页头下方。主题切换以整个文档为快照，细节见下节。页头不单独命名或截图，保留实时玻璃背后采样，避免独立快照破坏材质。语言、主题和路由切换期间，选中背景与外壳宽度继续使用自身的平滑移动和伸缩，不被正文的交叉淡化遮住。

## 图标

门户自有的菜单、终端、展开／还原与入场路牌箭头统一通过 `SiteIcon` 渲染。组件集中维护现有的 24 单位圆角线性图形，不为 CA 标识与共享库字标套用图标变形。运行时依赖使用 [morphicons](https://www.morphicons.com/) 的 Vue 入口，版本以 `package.json` 与锁文件为准。不另装图标集或复制变形算法。

菜单在打开时从四宫格变为关闭图形，Escape、外部点击和导航关闭时变回四宫格。终端展开与还原在同一个 SVG 路径上变形，不以条件路径、组件重建或交叉淡化替换图形。两处都直接读取原有展开状态，采用库提供的无过冲 `smooth` 弹簧，快速反向操作由库从当前图形接续。

首次渲染直接输出目标 SVG，不补播放水合动画。`reduced-motion="user"` 跟随系统偏好，减少动态效果时直接切换，卸载由 Vue 适配清理绘制任务。

图标使用统一的圆角端点、连接和线宽，颜色继承文字色，尺寸继续由共享控件或场景几何决定。装饰图标不进入无障碍树、不接收焦点，按钮保留原有双语标签和展开状态。共享 UI 内部的勾选与子菜单指示符仍由共享库维护，门户不依赖私有节点覆盖。
