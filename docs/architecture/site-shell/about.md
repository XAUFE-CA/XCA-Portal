# 关于学社页面

Status: adopted

本文描述关于学社的 Markdown 正文、MDC 容器、横幅与加载骨架。页面来源与内容集合见 [站点框架](README.md#页面与内容来源)，语言资源见 [翻译规则](../../terminology/translation.md)。

关于学社的标题与正文统一放在共享 `UiCard` 的 `glass-elevated` 卡片内，不直接铺在页面画布上。介绍依据 [学社公开资料](https://github.com/XAUFE-CA)。

`ContentRenderer` 渲染 Markdown 的标题、段落、列表与链接，排版复用共享 `neoverse-prose`，不为章节编写专用 Vue 模板或重复 CSS。正文与页面元信息只在对应语言的 Markdown 中维护。缺失内容时返回 404。

Markdown 通过原生 MDC 容器标记页面布局。`about-intro` 使用共享展示标题与导语字号，`about-values` 强调理念，`about-topic` 在宽屏双栏、不大于 `48rem` 时单栏，`about-participate` 与 `about-actions` 承载参与说明和操作入口。

正文容器带 `neoverse-prose`，操作入口放在正文排版范围之外，避免共享链接样式影响按钮。按钮通过 `ContentRenderer` 映射已有 `SiteActionLink`，保留共享默认尺寸、材质与焦点样式。

语言切换时两个入口跟随共享布局宽度过渡伸缩。起点在文案替换前采样，后一个按钮随前一个的宽度移动，减少动态效果或尺寸未变时不播放动画。

关于学社的“浏览公开项目”和“贡献指南”按钮在中英文页面均以 `target="_blank"` 打开，保留当前页面，并设置 `rel="noopener noreferrer"`。

新增双栏内容块时，在两份 Markdown 中使用相同的容器结构，不需要新增 Vue 模板：

```md
::section{.about-topic .neoverse-prose}

## 章节标题

章节正文。
::
```

卡片顶部展示学社横幅，路径、替代文本与原始尺寸来自 Markdown 的 `banner` 字段。两条路径直接引用组织总仓库 `XAUFE-CA/.github` 的 `profile/assets/xca-banner-light.webp` 与 `xca-banner-dark.webp`，门户不保存副本，也不做格式转换。

浅色使用 light 版本，深色使用 dark 版本，系统模式跟随 `prefers-color-scheme`。展示保留 3:1 比例，不裁切图片。两张图片通过 CSS 按根节点 `data-theme` 显示对应版本，使用原生懒加载，隐藏版本不占布局或无障碍阅读位置。根节点主题随 SSR 输出，因此图片选择不等待 Vue 水合。

横幅只在组织总仓库更新。源图尺寸变化时同步修改内容字段的 `width` 与 `height`。

正文查询使用不阻塞导航的懒加载。客户端跳转先渲染卡片骨架，服务端仍等待查询以直出正文。一次查询同时取回两种语言的正文，切换语言时按 `locale` 就地选取，卡片不会退回骨架，也不会在切换期间把横幅换成占位块。骨架样式取自共享 `UiSkeleton`，保留共享默认半透明填充与无障碍回退。

横幅占位保持 3:1，正文保留通栏与双栏结构，每节使用 1–2 条正文占位行，行间距取共享 `space-6`，区块间距取 `space-12`，`aria-busy` 标记加载中。取数完成后，骨架与正文在同一网格区域交叉淡化，离开的内容退出键盘与无障碍访问。

过渡沿用共享 `expressive` 时长与线性缓动，不增加取数等待时间，也不对服务端直出的正文补播放入场。首次查询错误直接抛出，后续查询错误交给错误页。缺失正文只在查询成功后按 404 处理，加载中不报错。

正文就绪后，横幅图片仍有独立的加载骨架。明暗骨架分别跟随对应图片的主题显示规则，只覆盖横幅固有比例区域，不参与正文布局。当前主题图片加载或失败结束后淡出对应骨架，切换主题不会复用另一张图片的完成状态。

横幅容器挂载时同步已完成的缓存图片，覆盖首屏水合与懒加载正文就绪两种情况，避免遗漏加载事件后残留骨架。正文与横幅过渡均遵循减少动态效果偏好，启用时立即切换。
