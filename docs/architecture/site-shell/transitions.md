# 页面过渡与层级

Status: adopted

本文描述路由、主题与语言切换的视图过渡、快照范围、页面层级、背景与共享玻璃接入。页头控件与宽度变化见 [站点导航与偏好控件](navigation.md)，关于学社正文加载见 [关于学社页面](about.md)。

路由切换与主题切换通过 View Transitions 完成，一次切换只呈现一个连续过程，不再是硬切。

语言切换同样不启动快照。共享极光玻璃边缘由文档层画布绘制，不在任何正文截图内，整页快照会让每张卡片在淡化期间失去折射边、变成扁平白板。截取整个文档则会把中英文页头词条叠进同一张快照。因此语言切换就地替换文案，不叠加第二层内容，也不做文字动画。任何两层文字的混合都会在字形层面被看成闪烁。页脚引语自己的点击切换不改变站点语言，按单层文字先出后进播放，不属于站点语言切换。页头词条、卡片正文与终端都直接替换。

只有盒子尺寸需要变化时才播放过渡。文案超出当前盒子时，盒子按共享 `spatial` 时长与缓动扩张或缩小，急速反向切换时从当前边沿接续而不是弹回任一端点。页头词条与关于学社的操作入口使用同一套布局宽度过渡。按钮在文案替换前采样自身宽度，再动画到新标签所需宽度，后一个按钮随前一个的宽度逐帧移动，不跳到新位置。扩张期间标签保持单行并就地裁剪，宽度追上后恢复自动尺寸。

路由切换由 Nuxt 的 `experimental.viewTransition` 承担，门户不重写路由流程。`view-transition.client.ts` 在过渡开始时给根节点写入共享 `data-neoverse-view-transitioning` 属性，使根快照沿用共享 `spatial` 时长与缓动。

路由过渡只截取正文。根节点不参与快照，正文分配 `root` 过渡名称，快照层裁剪到实时页头下方，页头因此保持实时玻璃采样。若页头仍有语言宽度动画在运行，Chrome 可能在截取进入快照时把实时玻璃重新采样为一帧白色。`view-transition.client.ts` 因此在路由更新完成、进入快照截取前暂停页头的背景采样，以共享回退底面保持不透明，并在快照绘制完成后立即恢复。退出快照与导航加载期间保持实时采样，普通路由不暂停。

主题切换改写的不只是正文，画布、页头与页脚同样换色，因此主题过渡以整个文档作为快照并取消该裁剪。否则只有正文在淡化，其余部分围绕淡化硬切。主题属性通过 `:not([data-neoverse-theme-view-transitioning])` 与正文规则互斥，两条规则同时命中时不会产生重复的 `root` 名称。

原生顶层表面（共享 `UiPopover` 菜单）绘制在快照之上，无法透过快照采样页面，玻璃材质会在整段淡化中失去模糊而显得透明。因此主题切换先由 `app/utils/top-layer.ts` 判定顶层是否已清空。菜单行在关闭自身面板的同一时刻提交偏好，面板要到下一帧才离开顶层，主题切换因此等待这次关闭再启动整页快照，而不是退化为硬切。只有持续打开的顶层表面（模态对话框）才直接提交，不启动快照。

来源页滚动后，根分组固定在截取时的正文盒模型，进入快照按目标页实时页顶偏移，交叉淡化期间两侧画面不再随分组几何滑动。页头落定引起的高度变化由同一偏移跟随。旧快照保留淡出终点，避免浏览器在移除快照树前的一帧恢复其不透明度。

过渡结束前再次导航时，新导航先终结旧快照，并不再为这次被中断的导航截取新快照，直接提交目的页，避免旧页画面在目的页上继续淡入后突然消失。路由落定后 1 秒内返回上一页同样直接提交，窗口从快照结束起算而非路由提交时，之后完成的导航恢复过渡。只有最新的一次过渡负责移除标记，快照准备失败时也会移除。

两者都遵循减少动态效果偏好与浏览器能力降级。不支持 View Transitions 或启用减少动态效果时直接更新内容，不播放动画。

停靠状态的终端卡片属于页面流，不单独占层。吸顶页头使用共享 `sticky` 层，短视口把终端卡片滚到页头下方时，页头仍绘制在上层。

首页入场与终端聚焦态由首页场景自身占层。入场使用 `overlay` 层并隐藏页头，聚焦使用 `modal` 层覆盖整屏。紧凑布局的菜单按钮使用共享 `UiPopover` 的 `trigger-variant="ghost"`，与导航项和设置控件一致，不显示次要按钮的实底色。

`nuxt.config.ts` 在样式表之前声明 CSS 层顺序，使基础重置层始终低于组件层，不依赖开发服务器的 SSR 样式链接顺序。声明使用固定的 `xca-cascade-order` key，服务端输出与客户端 Head 更新按同一标识复用。正文样式与共享控件保持各自的公开样式层，不提高选择器优先级覆盖基础重置。

页面底色使用共享 `surface-canvas` token。首页局部背景变量 `--xca-home-canvas` 在深色使用 `#060b13`，渐变色阶混合共享次要文字色推导。浅色以 `#f5f9fc` 为底色，中下部混合 8% 共享辅助色形成淡薄荷色，左上方叠加透明度为 8% 的共享主色线性渐变形成淡蓝色过渡。

深色下该叠层完全透明。背景采用大尺度低对比度渐变，其他路由保留共享画布底色。背景不创建额外节点或动画，随共享主题同步切换。终端和顶栏的极光玻璃材质继续由共享 UI 提供。

顶栏与终端复用共享极光玻璃材质，浏览器支持时由唯一共享 Glass Runtime 增强边缘折射。WebGL 不可用时由共享 CSS 回退。动画调用共享刷新能力，门户不建立第二套玻璃运行时。

应用卸载和热更新时销毁 Renderer，清理画布与监听。
