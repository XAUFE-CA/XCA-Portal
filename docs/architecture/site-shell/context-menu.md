# 上下文菜单

Status: adopted

本文描述页头、页脚、关于学社卡片、首页标题与终端区域的上下文菜单接入，以及菜单动作与提示条。挂载点清单见 [站点框架](README.md)，终端命令与会话接口见 [终端扩展接口](../terminal-extending.md)。

页头导航、页脚、关于学社卡片与首页标题各自挂载一份上下文菜单，终端区域另有一份。区域通过 `regionRef` 把指针、`contextmenu` 与触屏长按监听挂到自己的元素上，共享 `UiContextMenu` 负责面板定位、玻璃材质、键盘导航与焦点恢复。面板从指针处展开，下方空间不足时上翻，水平方向夹紧在视口内。

每个菜单末尾提供“显示原生菜单”。网页不能直接打开浏览器菜单，因此选择该项后显示操作提示，并让下一次右键、长按或菜单键操作交由浏览器处理。之后恢复自定义菜单。其他点击、按键或所属组件卸载会取消等待。

输入框默认保留浏览器菜单，因为自定义菜单无法提供拼写检查与辅助技术入口。终端区域例外。它的菜单提供“粘贴”与“复制选中内容”，因此在终端区域内接管命令行输入框。粘贴通过 `TerminalHost` 的 `insertText` 走原生编辑路径，保留撤销记录与建议状态。

终端菜单的其余动作通过已注册命令执行，不直接改写输出、历史或外观。复制、粘贴结果以短暂提示条说明。

提示条锚定视口下部并水平居中，不跟随指针，位置不随锚点或文案宽度变化。出现与退出按共享标准时长让透明度、模糊与缩放收敛，进入用减速曲线、退出用加速曲线，减少动效偏好下直接切换。

提示条经 `Teleport` 送到 `body`，用共享 `UiSurface` 的 `glass-immersive` 表面取得与面板一致的背景、边框、阴影和背景模糊，边缘交由共享 Glass Runtime 绘制。它声明 `data-neoverse-glass-occluder="topmost"`，使不吃指针事件的浮层参与边缘遮挡，并占用共享 `toast` 层，不受区域的玻璃层叠上下文限制。门户样式只保留视口几何、圆角、排版与出入场动效。

链接区域在新标签页打开时使用真实链接点击，避免面板获得焦点后 `window.open` 被当作弹窗拦截。

主题与语言使用二级菜单。点击行或悬停展开，左方向键回到顶层。二级菜单是顶层里独立的 manual 浮层，与面板边缘重叠一个边缘宽度以盖住父面板边缘，首行与父项对齐，右侧放不下时翻到左侧，垂直方向夹紧在视口内。

它自带同一玻璃材质，因此不会透出背后内容。主面板同样改为 manual 浮层，由共享运行时把二级菜单登记为内部元素，所以点击二级菜单不会关闭父面板，面板与二级菜单始终同时消失。

按到图片时，菜单在自己的行之后追加“复制图片”与“复制图片链接”。图像行由菜单状态按被按下的元素统一推导，任何已注册区域内的图片都自动获得，新增图片无需再接线。

复制图片优先写入原始字节。剪贴板不接受该格式（如 WebP）时，按取回的字节重新编码为 PNG 再写入，仍失败才回退为复制地址，并以同一提示条说明结果。

页脚是唯一显示构建信息的区域。按到构建提交链接时，菜单在链接项之后追加“复制构建提交”，复制产出本次构建的短 SHA。页脚其余位置与导航区域不提供该行，无 Git 信息的构建也不显示。
