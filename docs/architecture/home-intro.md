## 启动与会话

完整入场按浏览器标签页会话授予：`intro-session.client.ts` 在首次文档加载、路由跳转前记录入口地址并写入 `sessionStorage` 的 `xca-intro-session`，只有入口页是首页时才播放完整入场，每个文档至多一次。同一标签页内的刷新、与其他页面的往返和客户端路由返回使用短入场：顶栏及语言、主题控件直接呈现，标题与终端依次从下方进入，终端带轻微缩放并使用共享缓动减速到位，不挂载空间场景或播放启动日志。新标签页不具备该会话记录，因此重新播放完整入场。入口页不是首页时本次会话已完成入口判定，之后进入首页同样使用短入场。存储不可用时入口判定只在当前文档内有效，刷新后重新播放。客户端路由返回保留会话、命令输出和草稿。`xca intro` 重播前复用 `Session.resetWelcome` 恢复初始输出，保留命令历史、身份、目录和外观。重播、跳过和展开共用唯一的真实 TerminalHost，不创建替代终端或第二份会话。

短入场期间页面保持可交互，不设置全局入场标记、不挂载全屏遮罩，也不显示跳过动画控件。导航、主题切换与命令输入可与短入场并行。离开首页会取消旧动画，展开终端会先结束短入场再执行展开，视口或减少动画偏好变化会恢复稳定布局。入场背景不接收指针事件，完整入场归位时显示的导航也不等待动画结束。

首页画布与入场遮罩复用同一份背景底色及渐变定义，渐变按视口定位，首帧、CA 绘制和终端交接保持背景连续。场景雾化读取首页已解析的画布底色，沿用深浅色与系统配色的现有解析结果。

减少动画偏好下自动跳过空间入场，主动重播仍展示可读的启动消息与 ASCII，省略位移和缩放。文字阅读节奏独立于空间动画时长。`public/intro-gate.js` 在首帧前设置首页入场状态，避免正常布局提前闪现。入场状态仅在首页设置。

首页标题从 `app/data/hero-sentences.json` 读取双语轮播内容，`**...**` 标注使用强调色的文字，由 `app/components/home/hero-title.ts` 解析成纯文本与逐字序列；逗号只影响打字节奏，不决定强调范围。字符显现与删除按共享动效时长淡入淡出，唯一光标按字形度量随每个字符平滑移动，减少动画偏好下不播放过渡并隐藏光标。终端交互开始后，标题完成当前文字单元再暂停并隐藏光标。点击终端外部恢复，不能仅靠 mouseleave 恢复。

## 场景绘制

`CaIntroMark` 使用 `public/brand/ca-mark.svg` 的三个路径，并把导入的 `viewBox` 与宽高还原为 1254 单位，使页面裁剪不改变场景坐标。CA 保留原版闭合轮廓与 72 单位挤出厚度，不增加倒角。`MeshBasicMaterial` 不参与色调映射、雾化或环境照明，正面取主题前景色：深色主题为纯白，浅色主题为深色；顶点色保留原版按法线方向计算的中性侧壁明暗。道路、城市与报告厅的静态网格转换为 `BufferGeometry`，按材质合批并修正 Y 轴转换后的绕序。Three.js 相机读取现有 CSS 相机矩阵，不增加动画时钟。城市先绘制到离屏纹理，CA、道路与室内随后在主画布共用深度缓冲，牌面继续由 DOM 和 CSS 展示。标识透明度、厚度增长与摄像机运动共用填色进度。

场景使用 Three.js 的 WebGL2 渲染管线、`MeshStandardMaterial` 与 `MeshPhysicalMaterial`。室外两套主题天空和分区面光生成 PMREM，提供随粗糙度变化的环境反射，缓存至多两套配色。织物、地毯、穿孔板、石材、拉丝金属与路面的表面梯度参与 PBR 法线计算，金属、织物光泽与室外护栏玻璃透射由材质模型处理。天空以两层不同高度的云配合偏移密度采样近似自阴影与逆光银边，黄昏云层另有暖色透射，形成体积层次；不引入独立时钟或逐帧云动画。报告厅只使用灯光，不生成室内环境贴图，也不使用建筑玻璃折射与清漆反射，墙面、地面及上方嵌板采用不透明哑光饰面。室内所有材质保持深度写入，避免按材质合批时出现逐面透明排序错误。真实终端的极光玻璃仍由唯一共享运行时绘制，不受建筑材质变化影响。选择依据见 [Three.js 渲染决策](../adr/0001-three-intro-rendering.md)。

完整空间入场在 SVG 描边前等待 `prepareRenderer(signal)`：动态导入渲染模块，创建 WebGL2、静态网格、材质、PMREM 与离屏目标，通过 `compileAsync` 预编译离屏和主画布两种输出，再完成隐藏首绘。返回后等待两次动画帧回调，让准备与描边之间留出绘制机会，随后才启动 SVG 描边。相同 `AbortSignal` 取消后续启动与绘制，异步返回前再次检查取消和组件挂载状态。短入场不挂载空间场景，减少动画偏好不下载 Three.js。

摄像机从 C 左侧向上绕行，揭示平面标识的挤出厚度，再回正到 A 的开口前方进入道路。道路沿单个宽缓的水平弧线延展，道路视点由真实终端的入场显示高度确定，镜头看向弧线前方的采样点，不强制将俯仰和偏航归零。道路、护栏、路牌与支架共用空间曲线，两端的位置、斜率和曲率连续。道路显现的边界由当前摄像机位置决定，不另设运动时序，也不压缩弯道几何。

窄屏焦距由 `journeyPerspective` 根据视口宽度统一计算，CSS 路牌、WebGL 场景和真实终端的舞台投影共用结果，保留横向视野而不拉伸建筑或单独缩放牌面。标识起始距离与同一焦距匹配，穿过 A 的位置、道路轨迹和终端归位尺寸不随焦距改变。尺寸变化仍结束当前入场，不在播放中重建场景。

道路长度由 `intro-geometry.ts` 统一维护，入口、报告厅与城市退场随道路终点同步定位。六处路牌沿延长后的路段分布，牌面保持稳定朝向，标题来自现有双语资源，并标注真实路由或命令。路牌与支架复用安装坐标和显现函数，均位于连接段之前。桥面与连续护栏在道路终点处终止，桥墩不延伸进入连接段。相机节奏保留路牌阅读速度预算，不缩短路段为报告厅前场腾出空间。

场景颜色、圆角与时长基础值取自共享 UI 的公开 token，门户维护场景几何和节奏倍率。道路采用倒角截面，护栏采用连续圆角扶手、透射栏板与细立柱，不生成内部重复端盖。路面分段光迹与路缘导光带使用主题主辅色，流动进度取自现有摄像机位置。场景不独立实现页面背景模糊。WebGL2 不可用、初始化失败或上下文丢失时保留 SVG 标识与终端入场。准备期间取消立即释放资源，播放后的跳过保留场景冻结画面完成渐隐，卸载时释放几何、材质、图集、PMREM、离屏目标、阴影及监听，销毁渲染器并主动释放上下文。

场景配色从共享 UI 的公开基础色派生，与页面文字颜色分离。天空按首页画布亮度判定唯一的夜景或日景模式，两套各自拥有独立的天顶、地平线、雾色、云量、辉光与光源颜色，不互相插值：夜景从近黑深蓝过渡到冷蓝地平线，云量稀疏，以三层世界方向星场、银河带与少量亮星形成明显繁星；日景仍以蓝色天空为主体，采用蔚蓝天顶、浅青中层到微暖浅蓝地平线的三段渐变，叠加明确的低垂太阳圆盘、局部暖金霞光带与被逆光照亮的体积云，暖色不铺满天空，星场强度为零且不进入着色器星点分支。WebGL 路径按相机方向采样世界天空，视角旋转时云与星点固定在世界方向，不随视口平移；CSS 降级层按主题切换两套独立渐变与平铺星层，日景星层透明度为零，渲染器就绪后由内联变量提供精确色值，未挂载时回落到公开基础色。深色以冷白主光显露楼体，用有限距离的蓝色点光形成局部街区光池；浅色使用低角度暖光和远景雾化，楼体立面取明亮浅蓝、幕墙取蓝青玻璃、路面取明亮浅蓝，浅蓝雾只占窄带，避免深灰蓝或灰白把城市压暗。城市与室外道路共用灯光及环境反射，WebGL 天空、PMREM 与雾化读取同一套主题天空颜色。报告厅使用独立的材质配色与灯光层，关闭室内环境贴图和雾化，不消费室外天空环境。两侧明暗由首页画布亮度推导，不新增主题状态。仅报告厅生成一张 1024 × 1024 阴影图，平移时更新投影矩阵而不重绘贴图，相机与传送门裁切同样不触发重绘。配色同步时刷新阴影，场景平移不重新生成环境。

道路两侧的地块按共同街道网格布置，中低层街区之间设置四处高层地标，远景保留不对称高楼与开阔天空。建筑采用实体幕墙、倒角、收分楼层、承托裙房和薄屋面板，低位连廊连接同侧地块，不横跨高架道路中轴。街区和楼宇之间有连续地面、车道、交叉口标线、抬高步道、路灯、静态车辆及带树木和座椅的绿地，不把建筑放在道路或绿地上。建筑与设施一次生成，共用城市整体显现与退场，不增加独立时钟或逐帧几何。

Canvas 一次生成 2048 × 2048 材质数据图集，包含细密楼层、竖向结构线与稀疏分组窗灯，实际颜色从场景配色派生。窗灯以冷白为主，少量暖色与蓝紫强调，保留暗窗反射，不把整面楼体作为白色发光面。地标与部分办公塔增加细窄的立面和顶部灯冠，发光几何只占轮廓的一小段，不包裹整栋楼。图集驱动窗格、粗糙度与自发光，反射和高光由 PBR 与 PMREM 计算。纹理固定在建筑表面，使用重复采样与多级渐远纹理。建筑保持不透明，通过雾化体现距离。

城市不透明表面使用 Three.js 原生深度测试与深度写入，绘制到带深度缓冲的半浮点 HDR 离屏目标，不进行透明三角形排序。多重采样按 RGBA16F 实际支持的数量启用，不支持时使用单采样。完整城市图像保留原像素并提取局部 HDR 灯光辉光，经色调映射和显示颜色转换后，只在合成阶段应用一次 `cityOpacity`。随后室外与报告厅分别收集灯光，并在主画布共用深度缓冲，避免逐个立面淡出累积透明度。离屏目标与其他 GPU 资源一同释放，分配失败时沿用 SVG 降级。

`tests/e2e/city-fade-continuity.spec.ts` 固定摄像机，以小步长改变低区间透明度，读取实际合成像素并检查亮度连续性。`tests/e2e/intro-fade.spec.ts` 覆盖绘制阶段、首屏背景连续性与跳过时的资源释放。

道路终点后方的高层城市与近处街区形成深度差。路面降低大面积强调色染色，使用低幅颗粒、纵横接缝、粗糙度变化与路缘反射。细颗粒随距离衰减，纹理固定在场景坐标，不引入独立闪烁或运动。

道路采用高架标高，城市地面低于桥面。低层建筑与裙楼的屋顶位于桥面下方，中高层塔楼继续高于桥面。桥下横梁与桥墩延伸至城市地面，沿用道路曲线与显现进度。楼宇保留低处屋顶及下方立面的可见高度差，按观察距离雾化。摄像机与终端投影继续使用桥面坐标。

栏杆立柱落在沿道路曲线连续延伸的边梁上。外侧路牌底座通过承托梁连接桥面边缘。路牌、底座与承托梁整体沿安装点平移，承托梁内端与桥体重叠，避免弯道处断开。连接件与主体共用材质、显现及退场进度。

边梁与承托梁的承载面位于路面下方，栏杆立柱与路牌底座延伸到同一承载标高。承托结构不与行车表面形成共面重叠，避免摄像机移动时产生深度冲突。几何回归同时检查表面分离与底座连接。

## 报告厅

CA 与前段道路阶段不绘制报告厅内部及其宽地面，不让远处室内提前出现在标识后方。移除道路末端的两层独立光框，只保留报告厅入口；连接段接在道路终点处，六块路牌均位于连接段之前。原有的到达距离仍作为显现与退场的时序锚点，不再驱动光框几何。

入口采用传送门裁切。进入前，只有视线穿过门洞的室内片元参与绘制，门洞以外仍显示城市，不绘制报告厅外壳。入口前方的室内几何同时被剔除，避免目的场景的前墙挡住开口。镜头穿过入口平面后解除裁切，恢复完整室内。

门洞开口在末段道路随同一摄像机距离进度连续展开，并在镜头到达入口前达到完整宽高。开口两端的速度与加速度归零，内侧保留蓝青导光边缘。报告厅物体与静态网格保持最终位置和尺寸，不缩放家具或移动墙面，不使用场景透明度切换、黑屏遮罩或交叉淡化。裁切继续使用现有 WebGL 实例和深度缓冲，不增加第二套场景渲染器。

道路弯曲在道路终点之前归零，随后保持直线，使桥面外边缘与入口预留开口相接。入口沿用门洞宽高，连接地面沿原有道路生长前沿铺开，并与室内一起通过传送门裁切。道路视点延续到入口，仅在高终端净空不足时平滑补偿高度。完全越过入口顶板后，机位在向前推进的同时连续升高，视线保持水平，不靠仰角看向高处屏幕。靠近舞台前排座椅时终端即开始缩小，镜头继续前推和上升，不等镜头停止后才缩屏。摄像机沿同一条连续轨迹穿过开放入口。

中央通道两侧各有十排、每排六个座位，共 120 座。扩大后的厅宽、纵深与净高容纳连续阶梯承台、中央及两侧踏步和舞台前场，入口标高保持与道路相接，观众区向舞台逐排降低。每排共用承托梁、背壳连接梁、三个支脚和相邻座位间的扶手。靠背采用后倾、横向包覆和上下收分的曲面，坐垫采用鼓面，曲面法线随形体变换，不以圆角方盒替代软包。侧墙穿孔吸声板嵌入深色金属基座，上方使用哑光嵌板。五组悬浮顶棚、连续灯槽与侧轨共同界定空间。舞台和两级台阶以实心体落在室内地面上，不埋入地面或保留悬空踏步，前沿饰板保持在舞台与地面之间。只有入口连接段使用道路生长裁切，厅内地面、台阶和舞台始终保持完整。讲台和两侧扬声器落在舞台上，屏幕后墙保持连续哑光表面，装饰不进入玻璃投影。

报告厅使用独立的 `AuditoriumPalette`，不继承室外天空、楼体或灯光。银灰金属背壳、深蓝织物软包、中性穿孔吸声板、石墨色支撑、深色地毯与哑光石材分别配置颜色、粗糙度和表面细节。纹理固定在场景坐标，细织纹与穿孔随像素覆盖范围衰减，避免远处密纹闪烁。室内主光采用有限下射聚光灯，阴影视锥排除包围空间的屋顶，避免屋顶向后墙投下截断阴影。十处顶棚聚光灯从真实灯面下方垂直下照，两处舞台聚光灯朝向屏幕后墙提供局部洗墙光。发光面与顶棚、侧轨留有几何间隙，白色灯面的自发光只出现在朝下表面。低强度半球光只补暗部，不为补亮后墙提高整厅环境亮度。所有室内材质关闭环境反射，金属高光与织物光泽只响应直接光。夜间降低主光、洗墙光、顶棚光和灯具自发光，保留局部青蓝排座导光及踏步灯。空间场景绘制在真实终端下方，不遮挡终端。

`AUDITORIUM_OBJECTS` 是报告厅几何的唯一来源，包含稳定物体名称、位置、尺寸、材质分组与圆角参数。`AUDITORIUM.screen` 维护玻璃大屏的安装平面与宽高，舞台宽度与标高由同一空间配置维护。物体和静态网格各生成一次，不逐帧重建。空间数据不依赖 Vue、DOM 或播放器，可供后续场景选择使用。当前不提供漫游或物体选择接口，不增加第二套渲染器或会话。

## 终端交接

报告厅完整形成、舞台屏幕能透过入口前后开口后，唯一的真实 `TerminalHost` 先以宽幅玻璃屏显现。屏幕位置与尺寸来自 `AUDITORIUM.screen`，按同一摄像机距离投影。舞台与靠近舞台的座椅之间保留前场，屏幕下沿高于椅背，两侧及上方留出墙面与吊顶空间。扬声器和讲台落在扩大的舞台上，不占用屏幕范围。CA 与前段道路阶段保持不可见，不让玻璃从入口实体前墙外露出。

玻璃表面、折射边缘与光泽复用共享 UI 的极光玻璃，不另画幕布、屏幕边框或假终端。厅内通过升高机位观察屏幕，注视高度与机位高度同步变化，保持墙面竖线垂直。交接结束时，机位高度等于 `AUDITORIUM.screen.y`，屏幕中心投影到视口中央，而不是从低处仰视。居中移动前，玻璃四角使用同一相机姿态的完整透视投影。

透视宽屏阶段通过公开的 `data-neoverse-glass-edge-pass="css"` 使用极光玻璃的本地 CSS 折射边缘，让边缘与表面处于同一个透视平面，避免文档画布按外接矩形绘制出分离的方框。只有空间投影期间暂停背景模糊与边缘折射，保留材质色调、阴影和已绘制的描边，避免逐帧透视变换反复采样实时场景造成闪烁。`TerminalHost` 的 `projected` 状态由空间场景与归位开始信号共同派生，不绑定整个文字入场生命周期。开始归位时退出投影态，背景模糊与位移、缩放共用同一条 WAAPI 时间线，恢复目标直接引用共享滤镜 token，并尊重减少透明度偏好。正常归位与跳过复用同一组表面关键帧，欢迎文字打印前即恢复正常材质；进入 `ready` 只结束输出和交互限制，不再切换玻璃背景。短入场和减少动画的文字重播不暂停玻璃，不创建替代材质或第二个运行时。

机位从入口顶板后开始上升，终点直接取屏幕中心高度。高度曲线两端的速度与加速度归零，覆盖厅内推进和终端交接。道路末端至舞台的深度控制点间距逐步缩短，入厅后持续减速，不为提前缩屏增加突然加速的路段。终端的居中位移与尺寸收缩分别插值：机位开始上升时，玻璃从实际屏幕投影向视口中央平滑移动，在缩屏开始前完成居中；随后以该时点屏幕的实际投影尺寸连续收向终端尺寸，避免相机继续推进时反而放大。场景相机仍继续前推和上升，不冻结机位或先推完镜头再单独缩屏。

宽屏阶段隐藏标题栏、状态栏与输出，并禁止聚焦。文字显现使用独立的交接时点，在终端已居中、缩屏尚未完成时开始启动输出；终端尺寸收稳后，机位继续完成上升与推进。日志本身的阅读节奏不加速。跳过空白玻璃阶段时，内容等归位后再显示，避免文字随宽屏变形。报告厅在输出触发统一退场时离开，终端继续从当前实际投影归位。

空间退场由实际输出驱动：`boot.start` 开始日志并保留空间运动，补充推进在起止两端的速度与加速度归零，不在日志开始时突然叠加向前的速度。`boot.content` 触发道路与报告厅退场、页面显现及终端归位。`boot.ready` 等待归位完成后显示最后一行日志。日志完整播放后逐行输出欢迎字符画和文字，每一行随遮罩或淡入动效出现，不再整块跃入，然后启用正常命令输入。进度条表示阅读进度，不控制场景。

入场使用 WAAPI，这类变换不触发 CSS motion 事件。动画期间保留唯一共享 `glassRenderer.refresh()`，跟踪共享文档画布中的移动表面与遮挡，变换延迟期不逐帧刷新。透视宽屏的本地边缘随终端节点一起变换，不按外接矩形重建外轮廓。

## 中断与验证

入场期间在 700 毫秒内连续独立按下三次空格可跳过动画，长按重复、组合键、IME 和可编辑控件中的空格不计数，其他按键会重置计数。Escape 和跳过按钮共用平滑跳过流程：冻结现有场景，取消后续输出，再从终端当前投影过渡到正常布局，同时淡出场景。终端尚不可见时直接在最终位置淡入。减少动画偏好下直接恢复可读布局。

视口尺寸改变时结束入场并恢复正常布局。偏好变化、跳过和卸载取消同一组动画、异步任务与绘制。暂停与恢复不创建第二条时间线。

`tests/e2e/intro-outline.spec.ts` 人为延迟冷启动图形上下文，采样 SVG 描边进度并限制相邻采样跳变。[场景回归](../../app/features/intro/rendering/intro-scene.test.ts) 检查 Three.js 与 CSS 的投影一致性、Y 轴转换后的绕序、法线及道路坐标。测试不代替视觉验收或性能测量。

几何与网格单元测试位于入场模块的 `core/` 与 `rendering/`。[配色回归](../../app/features/intro/rendering/intro-scene-palette.test.ts) 检查独立日夜天空、材料明度差异、中性主光、夜间照明衰减与建筑哑光材质。[报告厅回归](../../app/features/intro/core/intro-auditorium.test.ts) 检查入口、屏幕净空、阶梯高差、联排支撑及舞台和台阶落地。[场景回归](../../app/features/intro/rendering/intro-scene.test.ts) 检查主灯阴影视锥覆盖中央通道并排除屋顶。[网格回归](../../app/features/intro/rendering/intro-mark-mesh.test.ts) 检查桥面、入口及阶梯中央通道的连续承托。[轨迹回归](../../app/features/intro/core/intro-journey.test.ts) 检查道路前视、门洞净空、机位上升的单调性与速度、终点高度及屏幕中心投影，以及上升与缩屏的重叠。`tests/e2e/intro-fade.spec.ts` 使用实际着色器检查传送门裁切、道路生长仅作用于连接段及资源释放。终端轨迹回归同时检查本地玻璃边缘。其他浏览器回归入口为 `tests/e2e/terminal-journey.spec.ts`、`terminal-intro-continuity.spec.ts`、`terminal-motion.spec.ts`、`home-entry.spec.ts` 与 `hero-typewriter.spec.ts`。检查方式见 [工程质量规则](engineering-quality.md#分级与执行责任)，自动化结果不等同最终视觉验收。

`tests/e2e/terminal-journey-camera.spec.ts` 通过 DOM 变更记录检查 Cruise 与 Retreat 的顺序、Brand 显现及逐行输出，并对最终就绪的真实终端执行命令。瞬时阶段不在跨浏览器调用后重复读取实时属性，避免窄屏已进入下一阶段时把正常推进判为失败。
