# 首页入场

Status: adopted

本文描述首页场景、启动输出与终端归位的协作。命令和会话接口见 [终端扩展接口](terminal-extending.md)，导航、主题与共享玻璃样式接入见 [站点框架](site-shell.md)。文档职责独立，源码由首页组件与入场特性模块共同承担。

## 启动与会话

完整入场按浏览器标签页会话授予：`intro-session.client.ts` 在首次文档加载、路由跳转前记录入口地址并写入 `sessionStorage` 的 `xca-intro-session`，只有入口页是首页时才播放完整入场，每个文档至多一次。同一标签页内的刷新、与其他页面的往返和客户端路由返回使用短入场：顶栏及语言、主题控件直接呈现，标题与终端依次从下方进入，终端带轻微缩放并使用共享缓动减速到位，不挂载空间场景或播放启动日志。新标签页不具备该会话记录，因此重新播放完整入场。入口页不是首页时本次会话已完成入口判定，之后进入首页同样使用短入场。存储不可用时入口判定只在当前文档内有效，刷新后重新播放。客户端路由返回保留会话、命令输出和草稿。`xca intro` 重播前复用 `Session.resetWelcome` 恢复初始输出，保留命令历史、身份、目录和外观。重播、跳过和展开共用唯一的真实 TerminalHost，不创建替代终端或第二份会话。

短入场期间页面保持可交互，不设置全局入场标记、不挂载全屏遮罩，也不显示跳过动画控件。导航、主题切换与命令输入可与短入场并行。离开首页会取消旧动画，展开终端会先结束短入场再执行展开，视口或减少动画偏好变化会恢复稳定布局。入场背景不接收指针事件，完整入场归位时显示的导航也不等待动画结束。

首页画布与入场遮罩复用同一份背景底色及渐变定义，渐变按视口定位，首帧、CA 绘制和终端交接保持背景连续。场景雾化读取首页已解析的画布底色，沿用深浅色与系统配色的现有解析结果。

减少动画偏好下自动跳过空间入场，主动重播仍展示可读的启动消息与 ASCII，省略位移和缩放。文字阅读节奏独立于空间动画时长。`public/intro-gate.js` 在首帧前设置首页入场状态，避免正常布局提前闪现。入场状态仅在首页设置。

首页标题从 `app/data/hero-sentences.json` 读取双语轮播内容。终端交互开始后，标题完成当前文字单元再暂停并隐藏光标。点击终端外部恢复，不能仅靠 mouseleave 恢复。

## 场景绘制

`CaIntroMark` 使用 `public/brand/ca-mark.svg` 的三个路径。网格沿原轮廓生成前后盖与连续侧壁，保留 CA 的凹形开口。CA 与道路使用同一深度缓冲，城市先以独立透明阶段绘制，侧板与牌面由组件和 CSS 展示。标识填色、厚度增长与摄像机运动同时启动，实体透明度和厚度取自同一填色进度。

摄像机从 C 左侧向上绕行，揭示平面标识的挤出厚度，再回正到 A 的开口前方进入道路。道路沿单个宽缓的水平弧线延展，道路视点由真实终端的入场显示高度确定，镜头看向弧线前方的采样点，不强制将俯仰和偏航归零。道路、护栏、路牌与支架共用空间曲线，两端的位置、斜率和曲率连续。道路显现的边界由当前摄像机位置决定，不另设运动时序，也不压缩弯道几何。

道路长度由 `intro-geometry.ts` 统一维护，双框、入口、报告厅与城市退场随道路终点同步定位。六处路牌沿延长后的路段分布，牌面保持稳定朝向，标题来自现有双语资源，并标注真实路由或命令。路牌与支架复用安装坐标和显现函数，均位于连接段之前。桥面与连续护栏在第二层光框处终止，桥墩不延伸进入连接段。相机节奏保留路牌阅读速度预算，不缩短路段为报告厅前场腾出空间。

场景颜色、圆角与时长基础值取自共享 UI 的公开 token，门户维护场景几何和节奏倍率。道路采用倒角截面，护栏采用连续圆角扶手、通透栏板与细立柱，不生成内部重复端盖。路面分段光迹、路缘导光带和栏板刻线使用主题主辅色，流动进度取自现有摄像机位置。道路保留透光、柔光与边缘色，不独立实现实时背景模糊。WebGL 不可用或上下文丢失时保留 SVG 标识与终端入场。卸载时释放缓冲、程序、监听与逐帧任务。

道路外围分三层布置低面数楼宇剪影，采用阶梯状退台、分离的塔冠、斜屋顶和裙楼轮廓，照明由连续屋顶轮廓光和成组楼层灯带构成，留空道路、路牌及报告厅所在轴线。远景按距离雾化，底部融入背景。显现与接近报告厅时的淡出均由同一摄像机位置驱动。楼宇沿用场景深度缓冲与整体退场，不维护独立时钟。深浅色共用道路染色比例、材质细节和光效算法，导光纹路统一使用有色线迹混合，不按主题或背景亮度分支计算。配色取自共享主题变量，主题及系统配色变化刷新同一绘制实例。

城市三角形按摄像机方向稳定地从远到近排列，以固定的立面透明度绘制到离屏纹理，再将完整城市按摄像机进度整体合成到场景，之后恢复深度写入并绘制道路与 CA。淡入淡出只在合成阶段应用一次，避免逐个立面量化低透明度时累积亮度跳变。仅在观察方向变化时更新排序，不以透明度阈值丢弃建筑片元。远处立面细线与灯带随距离平滑减弱，避免不足一个像素的细节闪烁。城市纹理、帧缓冲、程序与顶点缓冲随场景卸载或上下文丢失一并释放，分配失败时沿用 SVG 回退。

城市淡入淡出回归位于 `tests/e2e/city-fade-continuity.spec.ts`：固定摄像机，以小步长改变低区间透明度，读取实际合成像素并检查亮度连续性。`tests/e2e/intro-fade.spec.ts` 同时检查绘制阶段、首屏背景连续性与跳过时的城市纹理释放。

道路终点后方的高层城市横跨远处视野，与近处两侧楼宇形成深度差。立面以竖向分格、楼层分缝和宽幅反射区区分体块，远处细节随雾化减弱。路面使用低幅颗粒、纵横接缝、粗糙度变化与路缘反射，细颗粒随距离衰减。纹理固定在场景坐标，不引入独立闪烁或运动。

道路采用高架标高，城市地面低于桥面。低层建筑与裙楼的屋顶位于桥面下方，中高层塔楼继续高于桥面。桥下横梁与桥墩延伸至城市地面，沿用道路曲线与显现进度。楼宇底部雾化以城市地面为基准，保留低处屋顶及下方立面的可见高度差。摄像机与终端投影继续使用桥面坐标。

栏杆立柱落在沿道路曲线连续延伸的边梁上。外侧路牌底座通过承托梁连接桥面边缘。路牌、底座与承托梁整体沿安装点平移，承托梁内端与桥体重叠，避免弯道处断开。连接件与主体共用材质、显现及退场进度。

边梁与承托梁的承载面位于路面下方，栏杆立柱与路牌底座延伸到同一承载标高。承托结构不与行车表面形成共面重叠，避免摄像机移动时产生深度冲突。几何回归同时检查表面分离与底座连接。

## 报告厅

CA 与前段道路阶段不绘制报告厅内部及其宽地面，不让远处室内提前出现在标识后方。保留两层光框的原有造型、间距与照明，连接段接在第二层光框处，六块路牌均位于连接段之前。

入口采用传送门裁切。进入前，只有视线穿过门洞的室内片元参与绘制，门洞以外仍显示城市，不绘制报告厅外壳。入口前方的室内几何同时被剔除，避免目的场景的前墙挡住开口。镜头穿过入口平面后解除裁切，恢复完整室内。

门洞开口在末段道路随同一摄像机距离进度连续展开，并在镜头到达第一层光框前达到完整宽高。开口两端的速度与加速度归零，内侧保留蓝青导光边缘。报告厅物体与静态网格保持最终位置和尺寸，不缩放家具或移动墙面，不使用场景透明度切换、黑屏遮罩或交叉淡化。裁切继续使用现有 WebGL 实例和深度缓冲，不增加第二套场景渲染器。

道路弯曲在第一层光框之前归零，随后保持直线，使桥面外边缘与入口预留开口相接。双框与入口共用门洞宽高，连接地面沿原有道路生长前沿铺开，并与室内一起通过传送门裁切。道路视点延续到入口，仅在高终端净空不足时平滑补偿高度。完全越过入口顶板后，机位在向前推进的同时连续升高，视线保持水平，不靠仰角看向高处屏幕。越过靠近舞台的座椅后，缩屏接入仍在继续的上升过程。摄像机沿同一条连续轨迹穿过双框与开放入口。

中央过道两侧各有七排、每排五个座椅，并留有外侧通道。阶梯承台向舞台方向降低。坐垫与靠背采用连续圆角侧壁及倒角端面，扶手由细支撑连接座架。侧墙包含平整声学墙板、墙裙与细灯槽，顶部设置分层横梁、灯槽与连续侧轨。舞台包含分格前沿、台阶、讲台和两侧带格栅的扬声器。后墙不设置帘状竖板或褶皱纹理，舞台两侧使用横向金属构件，顶部增加悬浮构件与嵌入式导光线。

结构配色从共享画布色、道路色与强调色推导。浅色保留冰蓝与浅青色，深色使用低饱和石墨色、中性金属与深色织物，压低大面积墙面及舞台反射中的强调色比例。冷色主要用于细灯槽、过道导光与传送门边缘。配色按画布亮度连续混合，不新增主题状态源。金属保留定向高光，座椅保留低幅织物纹理，地面保留舞台方向反射。室内材质保持不透明，玻璃由真实终端的共享 UI 提供。空间场景绘制在真实终端下方，室内不透明表面不遮挡终端。

`AUDITORIUM_OBJECTS` 是报告厅几何的唯一来源，包含稳定物体名称、位置、尺寸、材质分组与圆角参数。`AUDITORIUM.screen` 维护玻璃大屏的安装平面与宽高，舞台宽度与标高由同一空间配置维护。物体和静态网格各生成一次，不逐帧重建。空间数据不依赖 Vue、DOM 或播放器，可供后续场景选择使用。当前不提供漫游或物体选择接口，不增加第二套渲染器或会话。

## 终端交接

报告厅完整形成、舞台屏幕能透过入口前后开口后，唯一的真实 `TerminalHost` 先以宽幅玻璃屏显现。屏幕位置与尺寸来自 `AUDITORIUM.screen`，按同一摄像机距离投影。舞台与靠近舞台的座椅之间保留前场，屏幕下沿高于椅背，两侧及上方留出墙面与吊顶空间。扬声器和讲台落在扩大的舞台上，不占用屏幕范围。CA 与前段道路阶段保持不可见，不让玻璃从入口实体前墙外露出。

玻璃表面、折射边缘与光泽复用共享 UI 的极光玻璃，不另画幕布、屏幕边框或假终端。厅内通过升高机位观察屏幕，注视高度与机位高度同步变化，保持墙面竖线垂直。交接结束时，机位高度等于 `AUDITORIUM.screen.y`，屏幕中心投影到视口中央，而不是从低处仰视。玻璃四角继续使用同一相机姿态的完整透视投影。

透视宽屏阶段通过公开的 `data-neoverse-glass-edge-pass="css"` 使用极光玻璃的本地 CSS 折射边缘，让边缘与表面处于同一个透视平面，避免文档画布按外接矩形绘制出分离的方框。恢复平面终端后移除该标记，交回唯一共享 Glass Runtime 绘制边缘，不切换材质或创建第二个运行时。

机位从入口顶板后开始上升，终点直接取屏幕中心高度，不再限制为半个门洞高度。高度曲线两端的速度与加速度归零，覆盖厅内推进和终端交接，不在缩屏开始时停顿。缩屏仍在越过座椅后开始，并与机位上升同时结束。交接期间持续更新屏幕投影，将矩阵连续收敛到视口中央的终端等比尺寸，不冻结机位或先完成上升再单独缩屏。

宽屏阶段隐藏标题栏、状态栏与输出，并禁止聚焦。缩放完成后，在原节点内开始日志。跳过空白玻璃阶段时，内容等归位后再显示，避免文字随宽屏变形。报告厅在输出触发统一退场时离开，终端继续从当前实际投影归位。

空间退场由实际输出驱动：`boot.start` 开始日志并保留空间运动。`boot.content` 触发道路与报告厅退场、页面显现及终端归位。`boot.ready` 等待归位完成后显示最后一行日志。日志完整播放后逐行输出欢迎字符画和文字，再启用正常命令输入。进度条表示阅读进度，不控制场景。

入场使用 WAAPI，这类变换不触发 CSS motion 事件。动画期间保留唯一共享 `glassRenderer.refresh()`，跟踪共享文档画布中的移动表面与遮挡，变换延迟期不逐帧刷新。透视宽屏的本地边缘随终端节点一起变换，不按外接矩形重建外轮廓。

## 中断与验证

入场期间在 700 毫秒内连续独立按下三次空格可跳过动画，长按重复、组合键、IME 和可编辑控件中的空格不计数，其他按键会重置计数。Escape 和跳过按钮共用平滑跳过流程：冻结现有场景，取消后续输出，再从终端当前投影过渡到正常布局，同时淡出场景。终端尚不可见时直接在最终位置淡入。减少动画偏好下直接恢复可读布局。

视口尺寸改变时结束入场并恢复正常布局。偏好变化、跳过和卸载取消同一组动画、异步任务与绘制。暂停与恢复不创建第二条时间线。

几何与网格单元测试位于入场模块的 `core/` 与 `rendering/`。[报告厅回归](../../app/features/intro/core/intro-auditorium.test.ts) 检查入口通道与屏幕净空。[网格回归](../../app/features/intro/rendering/intro-mark-mesh.test.ts) 检查桥面与入口相接。[轨迹回归](../../app/features/intro/core/intro-journey.test.ts) 检查道路前视、门洞净空、机位上升的单调性与速度、终点高度及屏幕中心投影，以及上升与缩屏的重叠。`tests/e2e/intro-fade.spec.ts` 使用实际着色器检查门洞外不出现室内像素、开口连续展开且室内保持不透明、穿过后解除裁切，以及入口前方几何不形成外壳。终端轨迹回归同时检查本地玻璃边缘。其他浏览器回归入口为 `tests/e2e/terminal-journey.spec.ts`、`terminal-intro-continuity.spec.ts`、`terminal-motion.spec.ts`、`home-entry.spec.ts` 与 `hero-typewriter.spec.ts`。检查方式见 [工程质量规则](engineering-quality.md#分级与执行责任)，自动化结果不等同最终视觉验收。
