# 首页入场

Status: adopted

本文描述首页入场会话、短入场、标题轮播、启动输出与中断流程。空间场景、报告厅与终端投影交接见 [入场场景](intro-scene.md)。命令和会话接口见 [终端扩展接口](terminal-extending.md)，导航、主题与共享玻璃样式接入见 [站点框架](site-shell/README.md)。文档职责独立，源码由首页组件与入场特性模块共同承担。

## 启动与会话

完整入场按浏览器标签页会话授予。`intro-session.client.ts` 在首次文档加载、路由跳转前记录入口地址并写入 `sessionStorage` 的 `xca-intro-session`，只有入口页是首页时才播放完整入场，每个文档至多一次。

同一标签页内的刷新、与其他页面的往返和客户端路由返回使用短入场。顶栏及语言、主题控件直接呈现，标题与终端依次从下方进入，终端带轻微缩放并使用共享缓动减速到位，不挂载空间场景或播放启动日志。

新标签页不具备该会话记录，因此重新播放完整入场。入口页不是首页时本次会话已完成入口判定，之后进入首页同样使用短入场。存储不可用时入口判定只在当前文档内有效，刷新后重新播放。

客户端路由返回保留会话、命令输出和草稿。`xca intro` 重播前复用 `Session.resetWelcome` 恢复初始输出，保留命令历史、身份、目录和外观。重播、跳过和展开共用唯一的真实 TerminalHost，不创建替代终端或第二份会话。

短入场期间页面保持可交互，不设置全局入场标记、不挂载全屏遮罩，也不显示跳过动画控件。导航、主题切换与命令输入可与短入场并行。离开首页会取消旧动画，展开终端会先结束短入场再执行展开，视口或减少动画偏好变化会恢复稳定布局。入场背景不接收指针事件，完整入场归位时显示的导航也不等待动画结束。

首页画布与入场遮罩复用同一份背景底色及渐变定义，渐变按视口定位，首帧、CA 绘制和终端交接保持背景连续。场景雾化读取首页已解析的画布底色，沿用深浅色与系统配色的现有解析结果。

减少动画偏好下自动跳过空间入场，主动重播仍展示可读的启动消息与 ASCII，省略位移和缩放。文字阅读节奏独立于空间动画时长。`public/intro-gate.js` 在首帧前设置首页入场状态，避免正常布局提前闪现。入场状态仅在首页设置。

首页标题从 `app/data/hero-sentences.json` 读取双语轮播内容，`**...**` 标注使用强调色的文字，由 `app/components/home/hero-title.ts` 解析成纯文本与逐字序列；逗号只影响打字节奏，不决定强调范围。字符显现与删除按共享动效时长淡入淡出，唯一光标按字形度量随每个字符平滑移动；基线取自当前字符的内联盒与字体上伸部，折行后仍对齐其所在行，不依赖会被排回上一行的零宽基线探针。减少动画偏好下不播放过渡并隐藏光标。终端交互开始后，标题完成当前文字单元再暂停并隐藏光标。点击终端外部恢复，不能仅靠 mouseleave 恢复。

## 启动输出

空间退场由实际输出驱动。`boot.start` 开始日志并保留空间运动，补充推进在起止两端的速度与加速度归零，不在日志开始时突然叠加向前的速度。`boot.content` 触发道路与报告厅退场、页面显现及终端归位。`boot.ready` 等待归位完成后显示最后一行日志。日志完整播放后逐行输出欢迎字符画和文字，第二屏使用独立的较快逐行节奏和共享快速淡入，结束后启用正常命令输入，不缩短前段日志的阅读间隔。进度条表示阅读进度，不控制场景。

标题栏和底部状态的启动文字、展开图标与帮助提示共用连续的交叉淡化，不随 `ready` 直接替换节点。控件的键盘与无障碍状态立即切换，视觉过渡及减少动画处理见 [终端扩展接口](terminal-extending.md)。

## 中断

入场期间在 700 毫秒内连续独立按下三次空格可跳过动画，长按重复、组合键、IME 和可编辑控件中的空格不计数，其他按键会重置计数。Escape 和跳过按钮共用平滑跳过流程。该流程冻结现有场景，取消后续输出，再从终端当前投影过渡到正常布局，同时淡出场景。终端尚不可见时直接在最终位置淡入。减少动画偏好下直接恢复可读布局。

CA 绘制阶段被打断时，空间场景随归位过渡淡出，但终端不跳到完成态。跳过流程继续调用同一个 `playBrand`，沿用第二屏的既有节奏与呈现，命令行在打印期间保持隐藏，字符画与欢迎文案逐行显现后才进入就绪态。跳过因此只省略空间场景，不省略文字入场。重播、卸载与视口变化取消同一组动画与异步任务，仍给出确定终态。

视口尺寸改变时结束入场并恢复正常布局。偏好变化、跳过和卸载取消同一组动画、异步任务与绘制。暂停与恢复不创建第二条时间线。
