# 术语与缩写对照

项目名和技术专名保留官方英文写法。普通概念使用中文，同一概念只用一种规范写法。

## 品牌与协作

| 术语 | 全称或解释 | 使用约束 |
| --- | --- | --- |
| XCA | XAUFE Computer Association（计算机学社） | 正文写 XCA |
| XAUFE | Xi'an University of Finance and Economics | 仅用于既有品牌，不引入学校官方 Logo |
| XAUFE-CA | GitHub 组织名 | 保留连字符与大写 |
| PR | Pull Request（拉取请求） | 正文写 PR |
| AI | Artificial Intelligence（人工智能） | 正文写 AI |
| UTF-8 | Unicode Transformation Format 8 | 文件编码写 UTF-8 |
| LF | Line Feed（换行符） | 文件行尾写 LF |
