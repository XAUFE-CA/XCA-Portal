# 首页空间场景使用 Three.js

Status: adopted

首页空间场景使用 Three.js 的 WebGL2 渲染管线，替代自行维护光照、反射与透明三角形排序。PBR、PMREM、深度测试与阴影由成熟管线承担，门户只维护场景几何、主题输入和必要的表面及合成逻辑，减少持续维护完整渲染管线的职责。

此次选择不迁移页面交互：镜头仍读取 DOM 的 WAAPI 变换，路牌保留 DOM 与 CSS，唯一的真实终端及极光玻璃继续使用共享 UI，不创建第二个动画时钟、终端或玻璃运行时。

CA 保留原版轮廓、挤出厚度与中性侧壁明暗，正面随主题使用前景色（深色为纯白、浅色为深色），不借迁移增加倒角或城市染光。报告厅和室外分别拥有灯光、材质配色及反射环境，避免外景配色侵入室内。

取舍是增加渲染依赖包体与初始化工作。Three.js 仅在完整空间入场时动态加载，SVG 描边前等待初始化、编译与隐藏首绘，减少动画偏好不下载该依赖。WebGL2 不可用、初始化失败或上下文丢失时保留 SVG 与终端入场，不维护另一套三维渲染实现。现行职责与生命周期见 [入场场景](../architecture/intro-scene.md)。
